# TaskbarStyleTool（任务栏透明工具）

轻量 Win10 任务栏透明调节工具（PowerShell + 系统 API / 注册表）。

## 使用步骤

1. 进入文件夹，双击 **`Start.bat`**
2. 弹出 **TaskbarStyleTool** 窗口后会自动 Apply  
   - **Alpha** 默认 `0`（尽量全透明）  
   - 可拖动滑条调节透明度，越小越透  
   - 可选样式：`Transparent` / `Blur` / `Acrylic`  
   - 改完后点 **Apply**
3. 想恢复系统默认：点 **Restore**，或直接关闭窗口  
4. 若任务栏异常闪动 / 样式乱了：运行 **`Restore.ps1`**  
   （右键 → 使用 PowerShell 运行）

## 系统要求

- Windows 10
- 系统透明效果需开启：  
  **设置 → 个性化 → 颜色 → 透明效果 = 开**

## 常见问题

**双击没反应 / 闪一下就关**  
右键 `Start.bat` → **以管理员身份运行**

**Apply 了但几乎看不出透明**  
不同 Win10 版本对任务栏透明支持不一样，属于系统限制。可再确认透明效果已开启；仍无效时可改用微软商店的 **TranslucentTB**（更稳定）。

**图标居中没效果**  
Win10 任务栏图标区往往几乎占满整条栏，居中空间很小。勾选「Center icons」后若抖或不明显，建议关掉。

**发给别人时可以附一句**  
> 双击 `Start.bat`。无效就先开系统「透明效果」，再管理员运行；要还原点 Restore。

## 文件说明

| 文件 | 作用 |
|------|------|
| `Start.bat` | 一键启动（推荐） |
| `Run.ps1` | 主程序（带界面） |
| `Restore.ps1` | 强制还原任务栏样式 |
| `Stop.ps1` | 结束相关进程 |
| `Start-TaskbarStyle.ps1` | 旧版命令行脚本（可不发） |

## 说明

- 不替换系统文件，主要是运行时改任务栏窗口样式 / 注册表透明度项  
- 关闭工具或点 Restore 后一般会恢复；个别情况可注销一次或再跑 `Restore.ps1`
